# Zotero Reading Heatmap v0.6.0 说明文档

**Zotero Reading Heatmap** 是一款专为 Zotero 8 设计的阅读打卡与活跃度追踪插件。它能自动记录您在 Zotero 内置阅读器中的阅读时间，并以直观的 GitHub 风格热力图展示，同时支持多人阅读群组同步功能。

---

## 0. v0.6.0 更新要点（交接必读）

本次 v0.6.0 版本在原有功能基础上进行了重要的 UI 交互升级，主要包含以下三项新功能：

1. **周/月视图切换**：在侧边栏顶部新增了 `Week` 和 `Month` 切换按钮。周视图（Weekly View）以单行 7 格的紧凑形式展示本周的阅读数据，适合空间有限的场景；月视图（Monthly View）保持原有的完整日历网格展示。
2. **Summary 统计信息折叠**：在侧边栏顶部新增了 `Summary` 切换按钮，允许用户自由展开或折叠头部的统计信息面板（包含 Total 总时长、Active 活跃天数、Streak 当前连续打卡、Best 历史最高连续打卡）。
3. **多人视图图例换行优化**：修复了在群组视图（Group View）下，当侧边栏较窄时，SVG 格式的图例（Less ... More）会超出边界被截断的问题。现已将图例重构为 HTML `flex-wrap` 布局，能够根据侧边栏宽度自动换行，完美适配多成员展示。

> **技术实现备注**：所有 UI 渲染均严格使用 DOM API（`createElement` / `createElementNS`）实现，未使用 `innerHTML`，以兼容 Zotero 8 的安全策略。

## 1. 核心功能特性

### 1.1 自动化阅读追踪
插件通过后台静默运行的 `ReadingTracker` 模块，自动检测您在 Zotero 内置阅读器中的活动：
- **精准计时**：只有当阅读器标签页处于激活状态时才计入时间。
- **防挂机检测**：通过检测阅读器的滚动位置变化，如果在设定的时间内（默认 60 秒）没有发生任何滚动，将自动暂停计时，防止挂机刷时长。
- **数据本地化**：阅读数据（包含每天的总阅读时长、阅读文献列表）实时保存在本地 `zotero-reading-heatmap.json` 文件中，每 5 秒自动防抖保存。

### 1.2 灵活的热力图视图
在 Zotero 的右侧面板中，插件提供了丰富的可视化视图：
- **双模式切换**：支持完整的月度日历视图和紧凑的单行周视图。
- **自适应布局**：热力图会自动缩放以填满侧栏宽度，图例支持自动换行。
- **颜色分级**：根据最高阅读时长，自动将每天的阅读量分为 5 个颜色等级（浅灰到深绿）。
- **悬浮提示**：将鼠标悬停在某一天上，会显示当天的具体日期、阅读时长（如 1h30m）和阅读的文献数量。

### 1.3 多人阅读群组（云同步）
通过配置专属后端服务器，您可以与好友组建阅读打卡群组：
- **群组管理**：在设置面板中，您可以创建新群组（生成 6 位邀请码）或通过邀请码加入他人群组。
- **视角切换**：在侧栏底部，您可以随时在“个人视图（My View）”和“群组视图（Group View）”之间切换。
- **成员聚合展示**：群组视图中，顶部会显示所有成员阅读数据汇总的聚合热力图，下方则依次展示每个成员（以不同颜色区分）的独立热力图。
- **自动同步**：配置服务器后，插件每 5 分钟会自动在后台同步本地数据并拉取群组成员的最新数据。

### 1.4 数据导入与导出
为了方便老用户迁移和数据备份，插件提供了完善的数据接口：
- **导入 Zotero Style 数据**：支持从 Zotero Style 插件的 `zoterostyle.json` 文件或旧版的 `Addon Item` 笔记中提取历史阅读数据，并合并到当前记录中。
- **CSV 导出**：一键导出过去 365 天的阅读统计数据（日期、秒数、分钟数、文献数），方便在 Excel 或数据分析软件中进行二次处理。
- **JSON 备份**：导出完整的原始数据结构（包含所有历史记录和群组信息），用于跨设备迁移或安全备份。

## 2. 安装与配置指南

### 2.1 插件安装
1. 下载最新版本的安装包：`reading-heatmap-0.6.0.xpi`。
2. 打开 Zotero，点击顶部菜单栏的 **工具 (Tools)** -> **附加组件 (Add-ons)**。
3. 点击右上角的齿轮图标，选择 **从文件安装附加组件 (Install Add-on From File...)**。
4. 选择下载的 `.xpi` 文件并确认安装。
5. 重启 Zotero 即可生效。

### 2.2 基础设置
安装完成后，您可以在 Zotero 的 **编辑 (Edit)** -> **设置 (Preferences)** 中找到 **Reading Heatmap** 选项卡：
- **User Name**：设置您的昵称，该昵称将在多人阅读群组中展示给其他成员。
- **User Color**：自定义自己在本机及群组热力图中的颜色（支持十六进制色号，如 `#216e39`）。
- **Idle Threshold**：设置防挂机检测的阈值（默认 60 秒）。

### 2.3 服务器连接测试
如果您部署了专属的后端服务器：
1. 在设置面板的 **Server URL** 中填入服务器地址（例如：`http://47.103.118.129:3456`）。
2. 点击下方的 **Test Connection** 按钮。
3. 如果显示绿色的 `Connected! Server v1.0.0`，则说明服务器连接正常，您可以开始使用群组功能。

## 3. 项目代码结构（交接参考）

主脚本 `addon/chrome/content/scripts/reading-heatmap.js` 包含所有核心逻辑，分为 6 个主要 Section：

1. **StorageManager**：负责本地 JSON 数据的读写、每日/每周/每月统计数据的计算。
2. **ReadingTracker**：负责监听 Zotero 标签页切换和阅读器滚动事件，实现防挂机计时。
3. **SyncManager**：负责与后端 Express 服务器通信，处理设备注册、群组创建/加入、数据上传/下载。
4. **HeatmapRenderer**：负责将统计数据渲染为 SVG 热力图和 HTML 统计面板。
5. **StyleDataImporter**：负责解析和导入 Zotero Style 插件的历史数据。
6. **Zotero.ReadingHeatmap**：主控对象，负责初始化各模块、注册侧边栏 UI（`_renderMainView`）和处理用户交互。
